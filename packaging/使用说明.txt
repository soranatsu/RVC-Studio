RVC 声音工作台 1.2.5
Windows 10 / 11 64 位 · NVIDIA RTX 4060 / 4060 Laptop

安装
把整个 ZIP 解压到本地文件夹，双击 RVC-Studio-1.2.5-Setup.exe。
同目录的 .bin 文件是安装数据，必须全部保留；不要在压缩包里直接运行安装程序。
安装包已包含 Python、PyTorch CUDA 11.8、声音模型、索引和音频／视频转换所需组件，无需再装 Python 或 CUDA Toolkit。
建议安装到默认目录或自己有读写权限的目录，目标磁盘至少留出 18 GB。解压安装包还需额外空间。
电脑仍需装好 NVIDIA 显卡驱动。可从 https://www.nvidia.com/Download/index.aspx 获取官方驱动。
安装程序会按需安装 Microsoft Visual C++ 运行环境；用于微信通话时，保留“安装 VB-CABLE 通话声卡”。
允许 Microsoft / VB-Audio 官方程序的管理员提示；声卡安装后重启电脑。
已有正常 VB-CABLE 的电脑会自动跳过驱动安装，不会再次卸载或重装。

开始使用
从桌面“RVC 声音工作台”启动。界面显示与后台模型准备分别提示；后台准备期间可以选择文件和参数。
附带爱音、灯、乐奈、立希、素世、莫提斯、初华、睦、祥子、海玲、喵梦，以及原来的其他模型，共 15 个。
首次启动默认 +12 半音，可用 +6 / +12 / +18 按钮或滑块调整；其他声音参数沿用打包时的配置。
初华、睦、祥子、海玲、喵梦没有附带索引，因此选择这些模型时检索比例自动设为 0，这是正常状态。检索比例为 0 才表示关闭索引；如果主动选择非零检索比例但索引不存在或无效，会明确报错并要求修正，避免静默改变音色。索引中个别邻居无效时会丢弃；没有可用邻居的帧使用原始特征，并在诊断中记录。
自动检测本机设备，不会预设为某一款华为耳机。开始变声前确认选中的是自己的麦克风。
切换模型时先停止当前变声，选择后再次点击“开始变声”。
连接或断开设备后点“刷新设备”。默认使用 Windows WASAPI 当前端点列表，已从列表消失的选择会清空，需重新选择。可在“高级设置”切换兼容接口；WDM-KS 可能保留离线配对驱动名称，不能据此判断耳机已连接。
开机／打开程序不会自动开启麦克风，需点击“开始变声”。
首次点击开始后先准备音高模型，再启动音频，避免模型加载占用首段声音。峰值保护前瞻约5毫秒。
音质提示出现“高音扩展已启用”表示内部保护后恢复设定音调；“峰值保护”表示音量峰值过高，可降低输出响度。软件不会偷偷改动个别音符。

微信通话与自己的监听
变声器输入：实际麦克风。
变声器输出：CABLE Input (VB-Audio Virtual Cable)。
变声器“耳机监听”：选择实际耳机并勾选监听，就能听到处理后的声音。
微信麦克风：CABLE Output (VB-Audio Virtual Cable)。
微信扬声器：实际耳机。
微信版本若没有设备选择入口，可在 Windows“设置 → 系统 → 声音 → 音量混合器”选择微信的输入设备。
如果微信仍跟随默认麦克风，可临时把系统默认输入设为 CABLE Output；结束后再恢复原麦克风。
安装声卡可能改变系统默认音频设备，请保持系统／微信的播放设备为耳机。
只开启软件内的“耳机监听”；Windows 声音设置里的“侦听此设备”应关闭，避免听到两次声音。
监听列表包含当前接口全部输出设备，可选择耳机、音箱或声卡。自动选择优先使用耳机；勾选前确认设备，避免扬声器声音再次被麦克风收录。监听与主输出相同时复用主输出。
蓝牙耳机开麦后可能切换到通话音质；如果音质／延迟不理想，可使用电脑或 USB 麦克风，同时用耳机听。

音频／视频转换
选择“文件转换”，导入有音轨的音频或视频，选择模型与输出文件夹，点击转换。
导出处理后的 WAV 音频，支持中文文件名，不覆盖原文件或已有输出。每次普通转换会按歌曲名、模型名和时间建立独立结果目录，报告中保留实际推理帧、处理块、索引检索和耗时诊断。
处理的是输入文件里的整条音轨，不自动做人声与伴奏分离，不重新封装视频。
文件转换时声线粗细、实时静音阈值等不适用的设置会禁用。

智能翻唱
选择“智能翻唱”，导入音频或带音轨的视频，选择目标声音与输出目录。
完整歌曲选择“歌曲”，已分离的人声选择“纯人声”。精修模式使用附带的 BS-Roformer，快速模式使用较轻的人声分离模型。
默认勾选“自动分析并选择参数”，直接开始智能翻唱：全曲分析后，三组参数转换相同的高音、弱音和换气片段，按音高、缺声、谐波与非谐波噪声选择一组，再转换整首。不会强行把模型音色的频谱包络改成原声。
也可先点击“分析推荐”试听。试听采用统一响度。点击“锁定参数”或取消自动选择后，整曲使用当前手动参数。整体移调会让伴奏同步移调，保持歌曲速度和旋律关系。
任务处理中模型、来源和分析设置会暂时固定，取消或完成后恢复。修改分析条件后需要重新生成试听。
有声丢检表示检测器未能可靠识别输出音高，不直接等于听到了缺声；近静音和连续高音异常另外显示。低可信推荐需要试听确认。
翻唱可整体移调 -12 至 +12 半音，自动模式优先保留原调；实时 +6 / +12 / +18 选项保持可用。
高音扩展自动降低模型内部生成音域，再恢复到设定的最终音调；正常音域使用原生路径，只有需要时才做局部扩展，不会只压低输出音量。频谱只作为可疑八度折返的辅助校正依据，不会把频谱峰值直接当成人声音高。
输出端最多向上恢复 36 半音（约 8 倍频率）、向下恢复 24 半音，支持约 12.5–6400 Hz 的目标基频，并受输出采样率限制。跨越约 50–800 Hz 内部范围的高低音会分段处理，分别恢复设定音调，原编码含义保持不变；宽音域本身不再触发停止。真正超出恢复范围时明确提示，实时淡出当前块后恢复后续有效声音。
扩展不保证所有模型均有同样音色与听感；极端快速的大跨度跳音可能有短暂过渡失真，需要结合试听判断。谐波频率不等于基频。
动态跟随调节声音强弱变化，包络平滑调节过渡速度，输出响度独立控制。发布版默认：智能翻唱精修开启、快速分离关闭、去齿音/去混响/压缩关闭、保护值 0.33、索引检索比例 0.7；实时保护值为 0.33。用户已有的手动设置会保留。实时和翻唱的 coarse 音高编码按模型的对数音高标尺映射，频谱均衡或音色增强不会恢复超出模型范围的声线。
默认开启“匹配原音频响度”：先把翻唱人声匹配到原视频分离人声的整体响度，伴奏保持原响度，再合成输出。默认不把较安静的伴奏或底噪自动放大到固定 LUFS。最终超限峰值使用 4 倍超采样和 5 毫秒前瞻限幅，真峰值上限 -1 dBTP；限幅后的补偿最多 +1 dB，极端响亮的原曲仍可能存在响度差，报告显示实际结果。关闭匹配后才使用手动设置（默认完整混音 -16 LUFS、独立人声 -18 LUFS）。
默认保存到安装目录旁的 projects，本机为 D:\Steam\Application\RVC\projects；每次翻唱都会新建“歌曲名_模型名_时间”文件夹，原有成果不会覆盖。
导出 48 kHz / 24-bit WAV，并保留独立人声、伴奏及处理报告，可继续使用“人声＋BGM”调整音量。
去混响、去齿音和轻压缩是可选处理；先试听再决定是否保留，较强处理可能改变尾音与音色。
分析与分离结果会缓存，重复修改参数时可复用。源文件或模型变化后相关缓存重新计算。
处理时显示阶段与百分比。取消会立即反馈，后台未能正常退出时自动重建，已经完成的音频不会删除。
源文件已经削波或目标模型音域不足时，后处理不能恢复缺失细节；报告会显示相关指标。

字幕与剪映
选择“字幕识别”，导入音频／视频，选语言后点击“识别并导出字幕”。支持中文、英语、日语、粤语及自动检测；粤语使用独立的 Cantonese/yue 令牌。自动检测按约 30 秒音频块进行，混合语言歌曲建议分段校对。SRT 包含时间轴，TXT 为纯文本，均使用 UTF-8；日文歌曲建议明确选择日文。字幕偏移以秒为单位，正值延后、负值提前。
在剪映中使用“导入字幕／本地字幕”导入 SRT；如需要编辑文字，可打开 TXT。不同剪映版本菜单名称可能不同，字幕文件不需要本软件启动剪映。
识别保留原语言，不自动翻译。歌曲、合声与混响可能造成错字或错位，发布前需要校对。
智能翻唱中的“同时识别字幕”默认关闭，勾选后额外生成“字幕”文件夹；不勾选时保持原有转换耗时。

链接下载与翻唱
在“智能翻唱”的音频／视频输入框粘贴 Bilibili 视频链接，再点击“开始智能翻唱”。分 P 链接按指定 P 下载；勾选“同时识别字幕”可一次输出翻唱与字幕。精修模式仍默认使用 BS-Roformer。
本机已安装 Bili23 时自动检测常见路径，也可用“Bili23 位置…”指定 Bili23.exe。Bili23 必须为支持官方 MCP 的版本；本次验证为 2.20.0.0。本安装包没有重复安装 Bili23。
Bili23 未运行时可自动启用本地 MCP 并保存配置备份；已经运行但 MCP 未开启时，请在 Bili23 设置→高级→MCP 开启。首次使用尚无配置时，请先启动一次 Bili23。链接下载沿用它已有的下载位置和登录状态。
下载权限与 Bili23 登录账号一致。需要登录的视频请在 Bili23 自行登录，本软件不要求输入账号密码，登录由 Bili23 管理。失败消息显示在工作台中。
单次结果目录包含主成品、人声、伴奏、试听、报告；链接下载还包含素材原视频，启用识别后包含字幕。原始 Bili23 下载文件保留，同链接再次处理优先复用。
新生成的翻唱成果带所选模型中文名称，例如“歌曲名_RVC_爱音.wav”；人声、伴奏和随翻唱生成的 SRT/TXT 使用相同文件名。每次结果仍使用独立目录，不覆盖已有成果。

检测与修复
开始菜单“RVC 声音工作台 → 环境检测”会生成 logs\diagnostics.json，不采集麦克风声音。
界面先显示“后台引擎”；启动变声或转换时单独显示模型准备进度。环境检测报告中的 gpu_kernel_pass 为 true 表示显卡推理可用；否则请检查／更新 NVIDIA 驱动。
启动失败会显示 logs\startup_error.txt 的位置，可把这个错误报告用于排查。
如果 CABLE 设备缺失，重启电脑；仍缺失时，从开始菜单“安装通话声卡”右键以管理员身份运行，完成后再重启。
程序设置和导入模型保存在安装目录内。重装同一目录会保留用户设置；卸载不会删除未随安装包安装的自定义模型、输出音频或日志。
