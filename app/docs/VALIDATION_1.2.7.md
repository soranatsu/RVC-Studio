# 1.2.7 视频导出验收

本次修改接入普通 RVC 文件转换、智能翻唱和链接翻唱；音频推理、索引检索及原有响度处理保持现有链路。视频使用打包的固定版本 FFmpeg，复制原画面轨，只映射最终翻唱音频。

## CPU 自动检查

- `test_video_export.py`：两条原音轨被完整替换为一条新音轨；频率检查排除原 220 Hz 音轨，确认新 660 Hz 音轨；源/输出画面 framemd5 一致。
- 长音频裁齐、短音频补静音、非 MP4 兼容画面编码回退 MKV、NaN/Inf 拒绝、任务取消、已有目标和发布竞态防覆盖均通过。
- `test_video_workflow.py`：真实媒体解码、混音、视频导出、报告和最终发布，通过普通转换及智能翻唱两个入口；神经推理使用合成引擎替身，避免把 GPU 推理速度误写成媒体导出速度。
- 音频输入、关闭视频导出、内部试听候选不会导出视频；视频合成失败时不发布整套不完整成果。
- 现有智能翻唱 FLOAT 试听/等响度契约、无控制台日志流、多语言字幕导出、媒体响度与移调检查通过。修正了智能试听测试中两个过时夹具，未改变生产音高链路。
